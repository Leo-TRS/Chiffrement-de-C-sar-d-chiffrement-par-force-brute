# Chiffrement-de-C-sar-d-chiffrement-par-force-brute
Ce programme chiffre un message avec le code césar et peut aussi le déchiffrer en utilisant la méthode brute force

Le programme à 3 utilisations :

-La première est le chiffrement d'un message en suivant la méthode de chiffrement de César. 
-La seconde est le déchiffrement d'un message grace a la clé de déchiffrement quand elle est connue.
-La troisième est une méthode de déchiffrement d'un message quand la clé n'est pas connue. Le programme va essayer toute les combinaisons possible et les afficher.
